# EcoBin
Project description:
EcoBin is a quiz to help the users know to which recycling bin they should throw their waste. It is a series of "yes" "no" questions and it returns to which bin you should throw it and which bin you use the most, with the purpose of making it easier to recycle.

Requisites:
Before running the programe you have to
1. Have python in your computer
2. Have the pandas library installed
3. Download in the same folder preguntas_en.cvs and proyect phase 1.py

How to run the code:
1. Download proyect phase 1.py and preguntas_en.cvs in the same folder
2. Open on python the proyect phase 1.py
3. Install pandas by putting in the terminal pip install pandas
4. Run the program and a window will open
5. Answer the "yes" "no" questions
6. The quiz will return to which bin you should throw the waste
7. To do the quiz again click on "Do another test"

Implemented features:
1. A window created with Tkinter with buttons to make the program more interactive
2. The cvs file with all the possible responses from the users and an answer to all of them
3. The results file to save all the answers the user has gotten
4. Calculations of what bin the user throws more waste into using the results file
5. Simple design to the window and the buttons


How these features address the problem:
A lot of people struggle to know where to throw their wastes. EcoBin guides the users with a simple quiz, its simple and interactive format makes it easier to the user to understand and be able to recycle. At the end it gives you which percentage of times you throw in that bin, to be able to identify by yourself easier and remember the next time where to throw it without using the quiz.
